Good to know

Frequently asked questions

Important details before connecting real data.

Is this webpage connected to a live database?

No. This file is a responsive landing page and visual dashboard preview only. The figures shown are sample values. A backend and database must be configured separately before it can store or display real information.

Can I use my 1TB external hard drive?

It can be used for files and backups on a home server. For online access, the computer must remain powered on and connected, and you should configure secure remote access, access controls, and an independent backup. An external drive alone does not make a website publicly accessible.

Can I host this page on GitHub Pages?

Yes. This is a static HTML page suitable for GitHub Pages. GitHub Pages serves the frontend; it does not run your custom database server or backend API.

How will user accounts and uploads be secured?

The backend should enforce authentication, authorization, file-size and file-type checks, rate limits, HTTPS, and regular backups. Never place database passwords or service-role keys in frontend JavaScript.
